Linear Regression

Predicting track popularity from numeric audio features.

What is Linear Regression? A model that fits a straight-line relationship between inputs and a continuous output: y = w₁x₁ + w₂x₂ + ... + b. Here, y is popularity (0–100) and x are audio features (danceability, energy, loudness, etc.).

Why used here? Popularity is a continuous score, making this a regression problem, and linear regression gives a fast, interpretable baseline.

Ridge / Lasso / Elastic Net add a penalty on coefficient size (L2 / L1 / both) to reduce overfitting — Lasso can shrink unhelpful features' weights to exactly zero.

Metrics: MAE (average absolute error), RMSE (root mean squared error, penalizes big misses more), R² (share of variance explained, 1.0 = perfect).
