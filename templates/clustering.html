Clustering — Unsupervised Learning

Grouping tracks by audio character, with no popularity or genre label involved.

All four algorithms below cluster tracks using numeric audio features, scaled with StandardScaler first (so a feature like tempo, on a 0–200+ scale, doesn't dominate the distance calculation over danceability, which is 0–1). Default features are danceability, energy, valence — change them on each page. Clustering runs on a random sample of the cleaned dataset (not all ~90k rows) so the interactive controls (K, eps, min samples) recompute in under a second — this is disclosed on every clustering page.
K-Means
Partitions tracks into K groups by minimizing within-cluster distance to a centroid, starting from random initial centroids.
Open →
K-Means++
Same algorithm, but centroids are initialized farther apart on purpose — typically faster, more consistent convergence.

Hierarchical Clustering
Builds a tree of nested clusters (dendrogram) via bottom-up agglomeration — no need to pick K in advance.
